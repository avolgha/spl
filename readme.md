# spl

simple math equation solver written in c.

## features

- addition
- subtraction
- multiplication
- modulo
- [postfix notation](https://w.wiki/8KhJ)
- parenthesis (why would you use them in postfix notation?)
- probably memory leaks?

## roadmap

- [x] implement floating point numbers
- [ ] add a RNG

## self compile

```sh
$ make
$ ./spl "..."
```
